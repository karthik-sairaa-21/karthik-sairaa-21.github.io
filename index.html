About Project

TheatreClick is a movie booking web application designed to provide a seamless experience for users to browse and book movie tickets. Built using HTML, CSS, JavaScript, and Firebase for authentication and real-time database functionalities, the app allows users to view movie thumbnails on the homepage and access detailed movie information upon selection. The database structure includes collections for Users, Theaters, Screens, Movies, Showtimes, and Bookings, ensuring efficient data management. Currently, I am working on fetching theater details and available screens when a user selects a specific movie. This project showcases my skills in front-end development, database integration, and user authentication.
